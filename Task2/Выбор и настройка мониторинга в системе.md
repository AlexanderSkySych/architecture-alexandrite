# Мотивация
Внедрение мониторинга позволит:
1) Более конкретно определять места сбоев при их возникновении
2) Определять узкие места процесса обработки заказа.
3) Отслеживать ключевые показатели хранилищ данных


# Выбор подхода к мониторингу
Основным подходом к мониторингу предлагае/ выбрать подход RED

Requests Rate - Позволит создать представление об октивности пользователей.
Errors - Позволит составить представление об ошибках возникающих в системе.
Duration - Позволит отследить потенциальные узкие места в процессах сервисов. В перспективе это поможет определить приритетные сегменты сервисов для вынесния в отделные сервисы. Также это упростит дальнейшую настройку горизонтального масштабирования. Также эта метрика позволит отследить нагрузку на очередь задач, а это узкое место всей системы.

Отслеживаемые метрики:

- Number of requests (RPS) for internet shop API
- Number of requests (RPS) for CRM API
- Number of requests (RPS) for MES API

- Response time (latency) for shop API
- Response time (latency) for CRM API
- Response time (latency) for MES API

- Number of simultanious sessions for shop API
- Number of simultanious sessions for MES API

- Memory Utilisation for shop API
- Memory Utilisation for CRM API
- Memory Utilisation for MES API

- Number of HTTP 200 for shop API
- Number of HTTP 200 for CRM API
- Number of HTTP 200 for MES API

- Number of HTTP 500 for shop API
- Number of HTTP 500 for CRM API
- Number of HTTP 500 for MES API

- Memory Utilisation for shop db instance
- Memory Utilisation for MES db instance
- Size of S3 storage
- Number of message in flight in RabbitMQ

# План действий
1) Развернуть контейнер Prometheus
2) Настроить сбор метрик shop API. 
    
    Сначала настроим сбор метрик для одного приоретеного сервиса и запустим всю систеу мониторинга для него.
3) Развернуть контейнер Grafana
4) Настроить дашборды для метрик
5) Настроить сбор метрик RabbitMQ
6) Настроить сбор метрик CRM API
7) Настроить сбор метрик MES API
8) Настроить сбор метрик shop db
9) Настроить сбор метрик MES db
10) Настроить сбор метрик S3 хранилища
